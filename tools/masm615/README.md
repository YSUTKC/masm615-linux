# MASM 6.15 files

Place your legally licensed MASM 6.15 files here:

```text
ML.EXE
ML.ERR
LINK.EXE
LIB.EXE   # optional
```

`ML.EXE` is run through `tools/wibo` on Linux. `LINK.EXE` is run inside
headless DOSBox as `X:\masm615\LINK.EXE`.

These files are proprietary Microsoft binaries and are ignored by git.
